# Module 5 renumbering: notes

Pulled all four old pages' live text before touching anything. Turned out this needed more than a renumber, three of the four had real staleness once I actually read them.

## 5.11 → became 5.5, but retired rather than renumbered
Old 5.11 wasn't one page. It was an 8-page subtree (intro + 7 sub-pages: Top Stats, Quick Actions, Recent Sheets, Latest Scans, the Retailers tab, Sheet View, Custom Scans) walking through the pre-revamp dashboard UI. That entire tour is now covered properly by Module 6, built against the live product. Keeping it would mean two conflicting product tours in the same book, one current, one describing a UI that no longer exists.

I replaced the whole subtree with a single short page, 5.5, that just points to Module 6. If you disagree and want the old walkthrough content preserved somewhere (e.g. for historical reference), let me know, I didn't delete the original GitBook pages, only skipped bringing them forward.

## 5.12 → 5.6, straight renumber
The Partner Directory page had no product-specific staleness at all, wholesale suppliers, mentors, accountants, that kind of thing. Copied across word for word.

## 5.13 → 5.7, rewritten
Old 5.13 was a "Summary & What's Coming Next" page that recapped the old three-area structure (Dashboard / Retailers / Scans, with the blue/green/yellow badge system). That structure doesn't exist anymore. Rewrote the summary to point at Module 6 in general terms rather than re-describing the old nav, kept the Discord community section as-is since that's still accurate.
