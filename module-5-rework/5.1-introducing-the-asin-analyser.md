# 5.1 Introducing the ASIN Analyser

The ASIN Analyser is SourceSheets' own profitability tool. You'll find it in the left-hand menu under **Tools → ASIN Analyser**.

### Everything you need, in one place

SourceSheets is built to be the only tool you need to analyse a product and decide whether to buy it. The ASIN Analyser pulls live price, rank, offer, and fee data for any ASIN, so everything that goes into that decision sits on one screen, in the account you're already using, without a second subscription or a separate login to manage. If you've seen older versions of this blueprint mention third-party tools like SellerAmp or BuyBotPro, you can ignore that, this covers the same ground and more.

### What it does

Paste in an ASIN and it pulls together:

* Current buy box price, sales rank, and offer count
* A full profit and ROI breakdown against your own cost price
* Price and sales rank history
* Who's winning the buy box, and how often
* Every other seller currently on the listing
* Whether any of your other tracked suppliers also carry the same ASIN
* Amazon's fees and the product's package dimensions
* Whether you're eligible to sell it, and any alerts attached to it

Everything in Module 7's gate-based evaluation model comes from this one screen.

### Nothing to install

Because it's part of your SourceSheets account, there's no trial to start and no extension to add to your browser. If you're logged in to SourceSheets, it's already there.
