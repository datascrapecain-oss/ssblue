# 5.3 Setting Your Preferences

Before you rely on the ASIN Analyser for real decisions, set these once. They're what turn raw numbers into a clear pass or fail, and they're used everywhere in SourceSheets, not just this one tool.

Go to **Settings → Preferences**.

### Profitability defaults

Three numbers, applied automatically as your default filters whenever you open the viewer:

* **Minimum Profit**: the lowest per-unit profit you're willing to consider. Start at **£1.00** as a wide net, or set it closer to your actual Gate 1 threshold from Module 7 if you already know it.
* **Minimum ROI**: the lowest return on investment you'll accept, as a percentage. **20%** matches Gate 2's floor from Module 7, so start there rather than something looser.
* **Minimum Sales / mo**: the lowest estimated monthly sales you'll consider. A default of **50** filters out products too slow-moving to bother with.

These aren't hard rules. They're a starting filter, and you'll refine them as your own gate criteria firm up in Module 7.

### VAT status

Set this to match your actual position: **Not Registered** if you haven't registered for VAT, **VAT Registered** if you have. This single setting changes how profit and ROI are calculated across the entire platform, so get it right before you start evaluating real products. Most new sellers start Not Registered, since UK VAT registration only becomes mandatory once your rolling 12-month turnover passes £90,000, and update this setting the day that changes.

### Display preferences

**Card** or **Table** layout for how products are shown in the viewer. Card view is easier to read while you're learning; Table view fits more products on screen at once, useful once you're moving faster.

### Eligibility checks

Controls how SourceSheets checks whether you can actually sell a product:

* **On demand**: checked one at a time, when you ask
* **Bulk checks**: check several products at once from the viewer
* **Fully automatic**: checked for you as sheets load
* **Disabled**: no automatic checking

For a new seller working through daily sheets by hand, **Bulk checks** is the sensible default: nothing runs until you ask it to, but you're not clicking one product at a time either.

Set all four of these now. The rest of this module, and everything in Module 7, assumes they're already configured.
